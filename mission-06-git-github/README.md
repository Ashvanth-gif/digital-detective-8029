## 2. Work completed

### Git operations
- `git status` shows which files have changed.
- `git add` selects files for a commit.
- `git commit` saves the selected changes.
- `git log` shows earlier commits.
- `git push` sends my commits to GitHub.
- `git pull` gets changes from GitHub.

Staging means choosing which changes to include. A commit saves those changes in Git history.

### Branch and Pull Request
A branch is a separate place to work on changes. A Pull Request, or PR, asks others to review those changes before they are added to the main branch.
